# Local

Install in your R environment using the following command:

```R
install.packages('babelquarto', repos = c('https://ropensci.r-universe.dev', 'https://cloud.r-project.org'))
```

Then in your terminal, run the following command to install the Quarto CLI:

```bash
Rscript -e 'babelquarto::render_website()'
```
